# Wedding Planner 💍

Web pencatat keuangan pernikahan: tabungan bersama, anggaran vendor, dan pembayaran (DP/cicilan).

- **Tampilan:** HTML/CSS/JS statis, di-hosting di GitHub Pages
- **Data:** Google Sheets lewat Google Apps Script (`apps-script/Code.gs`), dilindungi PIN
- **Mode coba:** kalau `API_URL` di `config.js` kosong, data disimpan di browser saja

Langkah setup ada di [PANDUAN.md](PANDUAN.md).
